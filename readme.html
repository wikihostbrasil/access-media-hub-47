1. Introdução: JWT vs Sessão Tradicional

🔸 Autenticação Tradicional (Sessão)

  • Como funciona: Servidor cria sessão e armazena dados no servidor
  • Identificação: Cookie com Session ID
  • Armazenamento: Servidor (arquivos, memória, banco)
  • Escalabilidade: Difícil (precisa compartilhar sessões)
  • Stateful: Servidor mantém estado
// PHP Tradicional
session_start();
$_SESSION['user_id'] = 123;
$_SESSION['role'] = 'admin';

🔹 Autenticação JWT (Token)

  • Como funciona: Servidor gera token criptografado
  • Identificação: Token JWT no header Authorization
  • Armazenamento: Cliente (localStorage, sessionStorage)
  • Escalabilidade: Fácil (stateless, sem sessão no servidor)
  • Stateless: Servidor não mantém estado
// JWT
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
💡 Por que JWT?
JWT é ideal para APIs RESTful, aplicações SPA (Single Page Application) como React, e sistemas que precisam escalar horizontalmente. Neste projeto, o frontend React se comunica com a API PHP exclusivamente via JWT.

Anatomia de um JWT

Um token JWT é composto por 3 partes separadas por pontos:

eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJhcnF1aXZvLW1hbmFnZXIiLCJhdWQiOiJhcnF1aXZvLW1hbmFnZXItdXNlcnMiLCJpYXQiOjE3MDAwMDAwMDAsImV4cCI6MTcwMDA4NjQwMCwiZGF0YSI6eyJpZCI6IjEyMyIsImVtYWlsIjoidXNlckBleGFtcGxlLmNvbSIsInJvbGUiOiJhZG1pbiJ9fQ.signature_hash_here

// Parte 1: HEADER (algoritmo de criptografia)
{
  "alg": "HS256",
  "typ": "JWT"
}

// Parte 2: PAYLOAD (dados do usuário)
{
  "iss": "arquivo-manager",
  "aud": "arquivo-manager-users",
  "iat": 1700000000,
  "exp": 1700086400,
  "data": {
    "id": "123",
    "email": "user@example.com",
    "role": "admin"
  }
}

// Parte 3: SIGNATURE (assinatura criptográfica)
HMACSHA256(
  base64UrlEncode(header) + "." + base64UrlEncode(payload),
  JWT_SECRET
)

⚠️ Importante: Diferente de sessões PHP, o JWT não é destruído no servidor no logout. Ele continua válido até expirar. Por isso, é crucial:
  • Definir tempo de expiração curto (recomendado: 1-24 horas)
  • Remover o token do localStorage no logout
  • Implementar refresh token para sessões longas

O sistema valida a role do usuário periodicamente a cada 5 minutos via validate-role.php para detectar mudanças de permissões.

5. Trabalhando com Backend (PHP)

Estrutura Padrão de um Endpoint

Todo endpoint PHP segue esta estrutura:

<?php
// 1. Incluir arquivos de configuração
include_once '../config/cors.php';        // Headers CORS
include_once '../config/database.php';    // Conexão DB
include_once '../config/jwt.php';         // JWT Handler
include_once '../config/auth-security.php'; // Middleware

// 2. Inicializar objetos
$database = new Database();
$db = $database->getConnection();
$jwt = new JWTHandler();
$auth_security = new AuthSecurity($db);

// 3. Validar autenticação
$token = $jwt->getBearerToken();
if (!$token) {
    http_response_code(401);
    echo json_encode(array("error" => "Token não fornecido"));
    exit();
}

$user_data = $jwt->validateToken($token);
if (!$user_data) {
    http_response_code(401);
    echo json_encode(array("error" => "Token inválido"));
    exit();
}

// 4. Validar autorização (se necessário)
// $auth_security->requireAdmin($user_data['id'], 'criar_usuario');

// 5. Processar requisição
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // Obter dados
    $json = file_get_contents('php://input');
    $data = json_decode($json, true);
    
    // Validar dados
    if (empty($data['campo'])) {
        http_response_code(400);
        echo json_encode(array("error" => "Campo obrigatório"));
        exit();
    }
    
    // Executar lógica
    try {
        $query = "INSERT INTO tabela (campo) VALUES (:campo)";
        $stmt = $db->prepare($query);
        $stmt->bindParam(":campo", $data['campo']);
        
        if ($stmt->execute()) {
            http_response_code(201);
            echo json_encode(array(
                "message" => "Sucesso",
                "id" => $db->lastInsertId()
            ));
        } else {
            throw new Exception("Erro ao inserir");
        }
    } catch (Exception $e) {
        http_response_code(500);
        echo json_encode(array("error" => "Erro interno"));
    }
} else {
    http_response_code(405);
    echo json_encode(array("error" => "Método não permitido"));
}
?>

Como o Token é Enviado

O ApiClient em src/lib/api.ts automaticamente anexa o token JWT em todas as requisições:

class ApiClient {
  private baseURL: string;

  private async request<T>(endpoint: string, options: RequestInit = {}): Promise<T> {
    const token = localStorage.getItem('access_token');
    
    const headers: HeadersInit = {
      'Content-Type': 'application/json',
      ...(token && { 'Authorization': `Bearer ${token}` }),
      ...options.headers,
    };

    const response = await fetch(`${this.baseURL}${endpoint}`, {
      ...options,
      headers,
    });

    if (response.status === 401) {
      // Token expirado ou inválido
      localStorage.removeItem('access_token');
      localStorage.removeItem('user_data');
      window.location.href = '/auth';
    }

    const data = await response.json();
    
    if (!response.ok) {
      throw new Error(data.error || 'Erro na requisição');
    }

    return data;
  }

  // Métodos públicos
  async getFiles() {
    return this.request('/files/list.php');
  }

  async uploadFile(formData: FormData) {
    const token = localStorage.getItem('access_token');
    const response = await fetch(`${this.baseURL}/files/upload.php`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
      },
      body: formData, // Não enviar Content-Type para FormData
    });
    return response.json();
  }
}

export const apiClient = new ApiClient(API_BASE_URL);

Criando um Hook Customizado para API

Exemplo: src/hooks/useApiProducts.ts

import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { apiClient } from '@/lib/api';
import { toast } from '@/hooks/use-toast';

export interface Product {
  id: string;
  name: string;
  price: number;
  stock: number;
  created_at: string;
}

export function useApiProducts() {
  const queryClient = useQueryClient();

  // Listar produtos
  const { data: products, isLoading } = useQuery({
    queryKey: ['products'],
    queryFn: () => apiClient.getProducts(),
  });

  // Criar produto
  const createMutation = useMutation({
    mutationFn: (data: Partial<Product>) => apiClient.createProduct(data),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['products'] });
      toast({ title: 'Produto criado com sucesso!' });
    },
    onError: (error: Error) => {
      toast({ 
        title: 'Erro ao criar produto', 
        description: error.message,
        variant: 'destructive'
      });
    },
  });

  // Deletar produto
  const deleteMutation = useMutation({
    mutationFn: (id: string) => apiClient.deleteProduct(id),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['products'] });
      toast({ title: 'Produto deletado com sucesso!' });
    },
    onError: (error: Error) => {
      toast({ 
        title: 'Erro ao deletar produto', 
        description: error.message,
        variant: 'destructive'
      });
    },
  });

  return {
    products: products || [],
    isLoading,
    createProduct: createMutation.mutate,
    deleteProduct: deleteMutation.mutate,
  };
}

import { useState } from 'react';
import { useApiProducts } from '@/hooks/useApiProducts';

          </CardHeader>
          <CardContent>
            <form onSubmit={handleSubmit} className="space-y-4">
              <Input
                placeholder="Nome do produto"
                value={name}
                onChange={(e) => setName(e.target.value)}
                required
              />
              <Input
                type="number"
                step="0.01"
                placeholder="Preço"
                value={price}
                onChange={(e) => setPrice(e.target.value)}

            </form>
          </CardContent>
        </Card>
      )}

      <div className="grid grid-cols-1 md:grid-cols-3 gap-4">
        {products.map((product) => (
          <Card key={product.id}>
            <CardHeader>
              <CardTitle>{product.name}</CardTitle>
            </CardHeader>
            <CardContent>
              <p>Preço: R$ {product.price.toFixed(2)}</p>
              <p>Estoque: {product.stock}</p>
              {user?.role === 'admin' && (
                <Button 
                  variant="destructive" 
                  onClick={() => deleteProduct(product.id)}
                  className="mt-4"
                >
                  Deletar
                </Button>
              )}
            </CardContent>
          </Card>
        ))}
      </div>
    </div>
  );
}

Protegendo Rotas

Crie um componente de rota protegida:

// src/components/ProtectedRoute.tsx
import { Navigate } from 'react-router-dom';
import { useApiAuth } from '@/hooks/useApiAuth';

interface ProtectedRouteProps {
  children: React.ReactNode;
  requiredRole?: 'admin' | 'operator' | 'user';
}

export function ProtectedRoute({ children, requiredRole }: ProtectedRouteProps) {
  const { user, loading } = useApiAuth();

  if (loading) {
    return <div className="flex items-center justify-center h-screen">
      Carregando...
    </div>;
  }

  if (!user) {
    return <Navigate to="/auth" replace />;
  }

  if (requiredRole && user.role !== requiredRole) {
    return <div className="p-6">
      <h1>Acesso Negado</h1>
      <p>Você não tem permissão para acessar esta página.</p>
    </div>;
  }

  return <>{children}</>;
}

Frontend: Hook useApiComments.ts

import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { apiClient } from '@/lib/api';
import { toast } from '@/hooks/use-toast';

export function useApiComments(fileId: string) {
  const queryClient = useQueryClient();

  const { data: comments, isLoading } = useQuery({
    queryKey: ['comments', fileId],
    queryFn: () => apiClient.getComments(fileId),
    enabled: !!fileId,
  });

  const createComment = useMutation({
    mutationFn: (comment: string) => 
      apiClient.createComment({ file_id: fileId, comment }),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['comments', fileId] });
      toast({ title: 'Comentário enviado!' });
    },
  });

  return {
    comments: comments || [],
    isLoading,
    createComment: createComment.mutate,
  };
}

Exemplo 2: Upload de Imagem com Preview

import { useState } from 'react';
import { apiClient } from '@/lib/api';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { toast } from '@/hooks/use-toast';

export function ImageUpload() {
  const [file, setFile] = useState<File | null>(null);
  const [preview, setPreview] = useState<string | null>(null);
  const [uploading, setUploading] = useState(false);

  const handleFileChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const selectedFile = e.target.files?.[0];
    if (!selectedFile) return;

    setFile(selectedFile);
    
    // Gerar preview
    const reader = new FileReader();
    reader.onloadend = () => {
      setPreview(reader.result as string);
    };
    reader.readAsDataURL(selectedFile);
  };

  const handleUpload = async () => {
    if (!file) return;

    setUploading(true);
    try {
      const formData = new FormData();
      formData.append('file', file);
      formData.append('category_id', '1');

      await apiClient.uploadFile(formData);
      
      toast({ title: 'Imagem enviada com sucesso!' });
      setFile(null);
      setPreview(null);
    } catch (error) {
      toast({ 
        title: 'Erro ao enviar imagem',
        variant: 'destructive'
      });
    } finally {
      setUploading(false);
    }
  };

  return (
    <div className="space-y-4">
      <Input
        type="file"
        accept="image/*"
        onChange={handleFileChange}
      />
      
      {preview && (
        <div>
          <img 
            src={preview} 
            alt="Preview" 
            className="max-w-md rounded-lg"
          />
        </div>
      )}
      
      <Button 
        onClick={handleUpload} 
        disabled={!file || uploading}
      >
        {uploading ? 'Enviando...' : 'Upload'}
      </Button>
    </div>
  );
}

Implementando Refresh Token (Avançado)

Para sessões longas, implemente refresh tokens:

// api/auth/refresh.php
<?php
include_once '../config/cors.php';
include_once '../config/database.php';
include_once '../config/jwt.php';

$database = new Database();
$db = $database->getConnection();
$jwt = new JWTHandler();

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $json = file_get_contents('php://input');
    $data = json_decode($json, true);
    
    $refresh_token = $data['refresh_token'] ?? '';
    
    if (empty($refresh_token)) {
        http_response_code(400);
        echo json_encode(["error" => "Refresh token não fornecido"]);
        exit();
    }
    
    // Verificar refresh token no banco
    $query = "SELECT user_id, expires_at 
              FROM refresh_tokens 
              WHERE token = :token 
              AND revoked = 0";
    
    $stmt = $db->prepare($query);
    $stmt->bindParam(":token", $refresh_token);
    $stmt->execute();
    
    $token_data = $stmt->fetch(PDO::FETCH_ASSOC);
    
    if (!$token_data || strtotime($token_data['expires_at']) < time()) {
        http_response_code(401);
        echo json_encode(["error" => "Refresh token inválido ou expirado"]);
        exit();
    }
    
    // Buscar usuário
    $query = "SELECT u.id, u.email, p.role 
              FROM users u 
              LEFT JOIN profiles p ON u.id = p.user_id 
              WHERE u.id = :user_id";
    
    $stmt = $db->prepare($query);
    $stmt->bindParam(":user_id", $token_data['user_id']);
    $stmt->execute();
    
    $user = $stmt->fetch(PDO::FETCH_ASSOC);
    
    // Gerar novo access token
    $new_access_token = $jwt->createToken(
        $user['id'],
        $user['email'],
        $user['role']
    );
    
    http_response_code(200);
    echo json_encode([
        "access_token" => $new_access_token
    ]);
}
?>
